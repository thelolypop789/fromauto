## ขั้นตอน (ทำตามนี้ทุกชุด)

1. **อ่านไฟล์ที่เจ้าของส่งมา** แยก: ข้อที่มีโจทย์/ตัวเลือกพอ · ข้อที่ข้อมูลไม่พอ (ไม่ลง จดไว้ใน docstring) · คำตอบจาก AI (ตรวจซ้ำก่อนใช้)
2. **เทียบกับคลังก่อนเขียน** ค้นด้วยคำสำคัญใน `prep.questions` (status approved, topic ของวิชานั้น) ผ่าน `python3 scripts/prep/ops/ops.py sql -`
   - ตรงประเด็น + สร้างก่อน 14 พ.ย. → **ไม่เขียนซ้ำ** ติดป้ายให้ข้อเดิม: `update prep.questions set exam_tag = '<TAG>' where id in (...) and exam_tag is null`
   - ไม่มี / ตัวเลขต่างจากข้อสอบ → เขียนใหม่
3. **เขียนสคริปต์ชุด** `scripts/prep/recall_2569_<วิชา>_bank.py` ใช้ `bankkit.Bank` (ดู `recall_2569_soc_bank.py` เป็นแบบ)
   - `b.add(topic, level, ask, correct, [wrong×3], why, sub=<subtopic code>)` — ข้อถูกเขียนตัวแรก bankkit สลับตำแหน่งให้
   - **เขียนโจทย์ใหม่ด้วยคำของเรา ไม่ลอกจากภาพ** หาเฉลยเองตามหลักวิชา ทุกข้อมีคำอธิบาย (บอกด้วยว่าตัวลวงผิดเพราะอะไร) อ้างมาตรา/หลักการ
   - ห้าม `\n\n` ในโจทย์, ตัวเลือกห้ามซ้ำ
   - หลัง build ดูบรรทัด `correct is longest / big gaps` → ใช้ `b.shorter` (ย่อข้อถูก) / `b.longer` (ยืดตัวลวง) จนข้อถูกไม่ยาวโดดจนเดาได้
   - subtopic: `select code, name from prep.subtopics where topic='<topic>'`
4. **ป้าย (exam_tag) ที่ผู้ใช้เห็น**
   - ข้อที่ผู้สอบเล่า: `แนวข้อสอบ ครูผู้ช่วย สพฐ. รอบทั่วไป 2569 (จากผู้เข้าสอบ)` · source `เรียบเรียงใหม่ · <TAG>`
   - ข้อที่แต่งเพิ่มตามแนว: `แนวข้อสอบ<วิชา> 2569 (ยากและลึก)` · source `claude:authored · <TAG>` (หน้า /prep/past จัดกลุ่มตามป้ายโดยตัดวงเล็บท้าย)
   - เรียกว่า "แนวข้อสอบ" เสมอ ห้ามเขียน "ข้อสอบจริง"
5. **นำเข้า** status `approved` (ถ้าเจ้าของไม่สั่งให้รอตรวจ) origin `manual` ref `recall-2569-<วิชา>` + `content_hash` และ `where not exists` กันซ้ำ — ดู SQL generator ท้ายเซสชันนี้: สร้างไฟล์ SQL ด้วย python แล้ว `ops.py sql <file>` (SQL ยาวต้องส่งเป็นไฟล์)
6. **commit + push** สคริปต์และ `content/prep/bank-*.json` ขึ้น branch ของเซสชัน (ห้ามใส่ชื่อ/ข้อมูลส่วนตัวผู้ใช้ใน repo)
7. **รายงานเจ้าของ** ตาราง: ลงใหม่กี่ข้อแยกหมวด · ข้อที่มีในคลังก่อนสอบ (#id) · ข้อที่ไม่ลงเพราะข้อมูลไม่พอ · ข้อที่เฉลยต่างจากติวเตอร์/ผู้สอบ พร้อมเหตุผล

8. **อัปเดตตาราง "สถานะตอนนี้" ในไฟล์นี้** (เพิ่มแถววิชาที่ทำ + สคริปต์) แล้ว commit ไปพร้อมกัน เซสชันถัดไปจะได้เห็นสถานะล่าสุด

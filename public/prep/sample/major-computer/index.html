ข้อสอบครูผู้ช่วย วิชาเอกคอมพิวเตอร์ พร้อมเฉลย

แนวข้อสอบวิชาเอกคอมพิวเตอร์ วิทยาการคำนวณ การเขียนโปรแกรม เครือข่าย AI พร้อมเฉลยและคำอธิบาย ลองตอบในใจก่อน แล้วกด "ดูเฉลย"

ข้อ 1

AI เชิงสร้างสรรค์ (Generative AI) เช่น แบบจำลองภาษาขนาดใหญ่ มีลักษณะสำคัญอย่างไร

  1. ก. สร้างเนื้อหาใหม่ เช่น ข้อความหรือภาพ
  2. ข. ค้นหาเฉพาะเนื้อหาที่เก็บไว้แล้วมาแสดงซ้ำ
  3. ค. ตรวจสอบความจริงของทุกประโยคได้ถูกต้องเสมอ
  4. ง. ทำงานได้เฉพาะเมื่อไม่มีข้อมูลฝึก
ดูเฉลย
ตอบข้อ ก. โมเดลสร้างผลลัพธ์ใหม่จากรูปแบบสถิติในข้อมูลฝึก แต่ผลอาจคลาดเคลื่อน ผู้ใช้จึงต้องตรวจสอบเอง
ข้อ 2

ต้นไม้ทวิภาค (Binary Tree) ที่มี 4 ระดับ และทุกระดับเต็ม มีจำนวนโหนดทั้งหมดกี่โหนด

  1. ก. 8 โหนด
  2. ข. 15 โหนด
  3. ค. 16 โหนด
  4. ง. 31 โหนด
ดูเฉลย
ตอบข้อ ข. แต่ละระดับมี 1, 2, 4, 8 โหนด รวมเป็น 15 โหนด
ข้อ 3

ครูให้นักเรียนวางแผนจัดงานวันกีฬาสี โดยแบ่งเป็นงานย่อย เช่น สถานที่ อาหาร และการแข่งขัน กิจกรรมนี้ฝึกองค์ประกอบใดของการคิดเชิงคำนวณ

  1. ก. การคิดเชิงนามธรรม (Abstraction)
  2. ข. การแยกย่อยปัญหา (Decomposition)
  3. ค. การรู้จำรูปแบบ (Pattern Recognition)
  4. ง. การดีบัก (Debugging)
ดูเฉลย
ตอบข้อ ข. การแบ่งปัญหาใหญ่เป็นปัญหาย่อยที่จัดการได้ง่ายคือ Decomposition ส่วน Abstraction เป็นการเก็บเฉพาะสาระสำคัญ
ข้อ 4

คุณลักษณะ 3V ของข้อมูลขนาดใหญ่ (Big Data) ประกอบด้วยข้อใด

  1. ก. ความถูกต้อง ความปลอดภัย และความเป็นส่วนตัว
  2. ข. ต้นทุน เวลา และคุณภาพของโครงการข้อมูล
  3. ค. ปริมาณ ความเร็ว ความหลากหลาย (Volume, Velocity, Variety)
  4. ง. การรวบรวม การจัดเก็บ และการทำลายข้อมูล
ดูเฉลย
ตอบข้อ ค. Big Data มีปริมาณมาก เกิดและเปลี่ยนเร็ว และมีรูปแบบหลากหลาย ทั้งข้อความ ภาพ และเสียง
ข้อ 5

ข้อใดอธิบายความแตกต่างระหว่าง RAM กับ ROM ได้ถูกต้อง

  1. ก. RAM เก็บข้อมูลถาวรแม้ดับไฟ ส่วน ROM เก็บข้อมูลชั่วคราว
  2. ข. RAM อ่านได้อย่างเดียว ส่วน ROM เขียนทับได้ตลอดเวลา
  3. ค. RAM และ ROM เก็บข้อมูลชั่วคราวเหมือนกันทุกประการ
  4. ง. RAM เก็บข้อมูลชั่วคราวและหายเมื่อดับไฟ ส่วน ROM เก็บถาวร
ดูเฉลย
ตอบข้อ ง. RAM เป็นหน่วยความจำแบบ volatile ที่ใช้เก็บงานที่กำลังประมวลผล ส่วน ROM เก็บโปรแกรมพื้นฐานของเครื่องและคงอยู่เมื่อปิดเครื่อง
ข้อ 6

สัญญาอนุญาตครีเอทีฟคอมมอนส์แบบ CC BY กำหนดเงื่อนไขหลักข้อใดแก่ผู้นำงานไปใช้

  1. ก. ต้องจ่ายค่าตอบแทนทุกครั้งที่ใช้
  2. ข. ห้ามนำไปแก้ไขดัดแปลงทุกกรณี
  3. ค. ห้ามใช้ในโรงเรียนและมหาวิทยาลัย
  4. ง. ต้องให้เครดิตผู้สร้างงานเดิม
ดูเฉลย
ตอบข้อ ง. CC BY อนุญาตให้ใช้และดัดแปลงได้ โดยต้องระบุชื่อผู้สร้างสรรค์ตามเงื่อนไข
ข้อ 7

ที่อยู่ไอพีเวอร์ชัน 4 (IPv4) มีความยาวกี่บิต

  1. ก. 16 บิต
  2. ข. 48 บิต
  3. ค. 128 บิต
  4. ง. 32 บิต
ดูเฉลย
ตอบข้อ ง. IPv4 ใช้ 32 บิต แบ่งเป็น 4 ชุด ชุดละ 8 บิต ส่วน 128 บิตเป็นขนาดของ IPv6
ข้อ 8

ครูให้นักเรียนจับคู่ เขียนลูกศรสั่งเพื่อนที่แสดงเป็นหุ่นยนต์ให้เดินไปหยิบสมบัติบนแผนที่ในห้อง กิจกรรมนี้เหมาะสอนเรื่องใดที่สุด

  1. ก. การเข้ารหัสแบบสมมาตรและอสมมาตร
  2. ข. การเชื่อมตารางด้วย JOIN
  3. ค. การคำนวณขนาดไฟล์รูปภาพ
  4. ง. การลำดับคำสั่งอย่างเป็นขั้นตอนและการดีบัก
ดูเฉลย
ตอบข้อ ง. การเรียงคำสั่งให้ถูกต้องและแก้เมื่อหุ่นยนต์เดินผิดคือหัวใจของอัลกอริทึมและการดีบักแบบ Unplugged
ข้อ 9

โค้ด Python a = 5 b = 1 while a > 0: b = b * a a = a - 2 print(b) พิมพ์ค่าใด

  1. ก. 120
  2. ข. 8
  3. ค. 30
  4. ง. 15
ดูเฉลย
ตอบข้อ ง. a เป็น 5, 3, 1 แล้วหยุดเมื่อ a = -1 ค่า b = 1×5×3×1 = 15
ข้อ 10

การเข้ารหัสแบบสมมาตร (Symmetric Encryption) มีลักษณะสำคัญข้อใด

  1. ก. ใช้กุญแจสาธารณะเข้ารหัสและกุญแจส่วนตัวถอดรหัสเสมอ
  2. ข. ใช้กุญแจดอกเดียวกันในการเข้ารหัสและถอดรหัส
  3. ค. ไม่ต้องใช้กุญแจในการถอดรหัส
  4. ง. ใช้กุญแจที่เปลี่ยนไปทุกตัวอักษรแบบสุ่ม
ดูเฉลย
ตอบข้อ ข. ระบบสมมาตรใช้คีย์ร่วมกันทั้งสองฝั่ง ส่วนกุญแจสาธารณะและส่วนตัวเป็นลักษณะของการเข้ารหัสแบบอสมมาตร
ข้อ 11

การจัดกลุ่มลูกค้าตามพฤติกรรมการซื้อโดยไม่มีป้ายกำกับล่วงหน้า (Clustering) จัดเป็นการเรียนรู้ประเภทใด

  1. ก. การเรียนรู้แบบไม่มีผู้สอน (Unsupervised Learning)
  2. ข. การเรียนรู้แบบมีผู้สอน (Supervised Learning)
  3. ค. การเรียนรู้แบบเสริมกำลัง (Reinforcement Learning)
  4. ง. การเรียนรู้แบบท่องจำตายตัว (Rote Learning)
ดูเฉลย
ตอบข้อ ก. Clustering หากลุ่มตามความคล้ายของข้อมูลเอง โดยไม่มีคำตอบที่ถูกกำหนดไว้ล่วงหน้า
ข้อ 12

การเรียงลำดับแบบเลือก (Selection Sort) กับข้อมูล 6 ตัว ต้องเปรียบเทียบทั้งหมดกี่ครั้งตลอดการทำงาน

  1. ก. 15 ครั้ง
  2. ข. 6 ครั้ง
  3. ค. 12 ครั้ง
  4. ง. 36 ครั้ง
ดูเฉลย
ตอบข้อ ก. จำนวนการเปรียบเทียบเท่ากับ 5+4+3+2+1 = 15 ครั้ง
ข้อ 13

นักเรียนต้องหาลำดับตัวเลข 2, 4, 6, 8, ... ครูให้พิจารณาว่าตัวถัดไปเพิ่มทีละ 2 กิจกรรมนี้ฝึกองค์ประกอบใดของการคิดเชิงคำนวณเป็นหลัก

  1. ก. การแยกย่อยปัญหา (Decomposition)
  2. ข. การออกแบบอัลกอริทึมเชิงขนาน
  3. ค. การทดสอบและแก้ไขข้อผิดพลาด
  4. ง. การรู้จำรูปแบบ (Patterns)
ดูเฉลย
ตอบข้อ ง. การสังเกตความซ้ำหรือความสัมพันธ์ในข้อมูลเพื่อสรุปกฎ คือการรู้จำรูปแบบ
ข้อ 14

เหตุใดมาตรฐาน Unicode จึงเหมาะกับการแสดงอักษรไทยมากกว่า ASCII

  1. ก. Unicode รองรับตัวอักษรหลายภาษาในระบบเดียว
  2. ข. Unicode ใช้เพียง 7 บิตต่อหนึ่งตัวอักษร
  3. ค. Unicode ไม่ต้องใช้ฟอนต์ในการแสดงผล
  4. ง. Unicode ออกแบบมาสำหรับตัวเลขโดยเฉพาะ
ดูเฉลย
ตอบข้อ ก. ASCII มีเพียง 128 ตัวอักษรและไม่มีอักษรไทย ส่วน Unicode กำหนดรหัสให้อักษรของหลายภาษารวมทั้งไทย
ข้อ 15

ต้องการแสดงรายการขั้นตอนที่มีหมายเลข 1, 2, 3 โดยอัตโนมัติ ควรใช้แท็ก HTML ใด

  1. ก. <ul> ร่วมกับ <br>
  2. ข. <ol> ร่วมกับ <li>
  3. ค. <table> ร่วมกับ <td>
  4. ง. <p> ร่วมกับ <hr>
ดูเฉลย
ตอบข้อ ข. <ol> สร้างรายการแบบเรียงลำดับตัวเลข ส่วน <ul> สร้างรายการแบบจุดนำหน้า

ซ้อมสอบ SOBPREP · ตัวอย่างข้อสอบ

ข้อสอบครูผู้ช่วย วิชาเอกศิลปศึกษา พร้อมเฉลย

แนวข้อสอบวิชาเอกศิลปศึกษา ทัศนธาตุ ประวัติศาสตร์ศิลป์ ศิลปะไทย การสอนศิลปะ พร้อมเฉลย ลองตอบในใจก่อน แล้วกด "ดูเฉลย"

ข้อ 1

กลุ่มสาระการเรียนรู้ศิลปะในหลักสูตรแกนกลางการศึกษาขั้นพื้นฐาน พุทธศักราช 2551 แบ่งเป็นสาระใดบ้าง

  1. ก. ศิลปะไทย ศิลปะสากล ศิลปะพื้นบ้าน
  2. ข. วาดภาพ ปั้นรูป พิมพ์ภาพ
  3. ค. ทัศนศิลป์ ดนตรี นาฏศิลป์
  4. ง. ทฤษฎีสี ทัศนมิติ องค์ประกอบศิลป์
ดูเฉลย
ตอบข้อ ค. กลุ่มสาระศิลปะของหลักสูตรแกนกลางแบ่งเป็นสามสาระ คือทัศนศิลป์ ดนตรี และนาฏศิลป์
ข้อ 2

ขั้นตอนการวิจารณ์ศิลปะตามแนวของเฟลด์แมน (Feldman) เรียงลำดับตามข้อใด

  1. ก. ตัดสิน ตีความ วิเคราะห์ บรรยาย
  2. ข. ตีความ บรรยาย ตัดสิน วิเคราะห์
  3. ค. บรรยาย วิเคราะห์ ตีความ ตัดสิน
  4. ง. วิเคราะห์ ตัดสิน บรรยาย ตีความ
ดูเฉลย
ตอบข้อ ค. แนวของเฟลด์แมนเริ่มจากบรรยายสิ่งที่เห็น วิเคราะห์ ตีความ แล้วตัดสินคุณค่าเป็นลำดับสุดท้าย
ข้อ 3

นักเรียนวาดรูปท่อนไม้บนกระดาษเรียบและใช้ดินสอขีดเป็นเส้นสั้นๆ ให้ดูคล้ายลายเสี้ยนไม้ พื้นผิวลักษณะนี้คือข้อใด

  1. ก. พื้นผิวจริง สัมผัสได้ด้วยมือ
  2. ข. พื้นผิวเรียบเสมอ ไม่มีลวดลาย
  3. ค. พื้นผิวลวงตา สัมผัสได้ด้วยสายตา
  4. ง. พื้นผิวสามมิติที่นูนขึ้นจากกระดาษ
ดูเฉลย
ตอบข้อ ค. การเขียนให้ดูเหมือนผิวไม้บนกระดาษเรียบเป็นพื้นผิวลวงตา เพราะเมื่อสัมผัสกระดาษยังคงเรียบ
ข้อ 4

สินเทาในจิตรกรรมฝาผนังไทยมีหน้าที่ใดเป็นหลัก

  1. ก. เป็นสีพื้นหลังสำหรับระบายท้องฟ้ายามเย็นทั้งผืน ในทุกฉากของเรื่อง
  2. ข. เป็นแถบหรือเส้นคั่นแบ่งฉากหรือแบ่งเหตุการณ์ในภาพ
  3. ค. เป็นลวดลายประดับขอบล่างของผนังด้านที่ติดพื้น
  4. ง. เป็นเส้นร่างเบื้องต้นที่ช่างลบทิ้งก่อนลงสีจริง
ดูเฉลย
ตอบข้อ ข. สินเทาเป็นเส้นหรือแถบที่ใช้แบ่งฉากแต่ละตอนของเรื่อง เช่น ใช้เป็นกำแพง เส้นทางหรือแนวหิน
ข้อ 5

ถ้ำอชันตาในอินเดียมีชื่อเสียงด้านใด

  1. ก. ภาพพิมพ์แกะไม้เรื่องคนเดินทาง ที่เล่าเรื่องการเดินทางข้ามทะเล
  2. ข. เครื่องปั้นดินเผาเคลือบสีเขียว
  3. ค. ภาพเขียนสีน้ำมันสมัยใหม่
  4. ง. จิตรกรรมฝาผนังและประติมากรรมเกี่ยวกับพุทธศาสนา
ดูเฉลย
ตอบข้อ ง. ถ้ำอชันตามีภาพเขียนฝาผนังและประติมากรรมที่เล่าเรื่องชาดกและพุทธประวัติ
ข้อ 6

ครูให้นักเรียนชั้นประถมต้นตัดกระดาษเพื่อทำงานคอลลาจ ควรเตรียมอุปกรณ์ข้อใดเพื่อความปลอดภัยที่สุด

  1. ก. มีดคัตเตอร์ใบมีดคมขนาดใหญ่
  2. ข. ใบมีดโกนสำหรับตัดกระดาษหนา
  3. ค. กรรไกรตัดโลหะแผ่นหนา
  4. ง. กรรไกรปลายมนที่เหมาะกับขนาดมือเด็ก
ดูเฉลย
ตอบข้อ ง. เด็กเล็กควรใช้กรรไกรปลายมน ซึ่งลดความเสี่ยงบาดเจ็บ ไม่ควรใช้ของมีคม
ข้อ 7

เทคนิคแรเงาด้วยการขีดเส้นขนานถี่ๆ และขีดไขว้ซ้อนทับเพื่อเพิ่มความเข้ม เรียกว่าอะไร

  1. ก. สติปลิง (stippling) ที่ใช้จุดเป็นหลัก
  2. ข. เบลนดิง (blending) ที่ใช้ไล่เกลี่ยด้วยนิ้ว และผสมให้กลืนเข้าหากัน
  3. ค. ฮาร์ชิง (hatching) และครอสฮาร์ชิง (cross-hatching)
  4. ง. กราเดชัน (gradation) ที่ใช้สีเปียกแผ่ซึม
ดูเฉลย
ตอบข้อ ค. การขีดเส้นขนานเรียกฮาร์ชิง และเมื่อขีดไขว้ทับเรียกครอสฮาร์ชิง ใช้เพิ่มน้ำหนักแสงเงา
ข้อ 8

รูบริก (rubric) ในการประเมินผลงานศิลปะ คืออะไร

  1. ก. ข้อสอบปรนัยที่มีตัวเลือกสี่ข้อ
  2. ข. รายชื่อนักเรียนที่เข้าห้องเรียนศิลปะ ที่ครูใช้ตรวจเช็คชื่อทุกชั่วโมง
  3. ค. แบบบันทึกเวลาที่ใช้ทำงานของนักเรียน
  4. ง. แนวทางให้คะแนนที่ระบุเกณฑ์และระดับคุณภาพอย่างชัดเจน
ดูเฉลย
ตอบข้อ ง. รูบริกบอกเกณฑ์และคำอธิบายแต่ละระดับ ช่วยให้การประเมินเป็นมาตรฐานและโปร่งใส
ข้อ 9

เด็กอายุ 5 ปีวาดคนเป็นวงกลมใหญ่มีตาปากและมีเส้นเป็นแขนขา ครูควรตอบสนองอย่างไรจึงเหมาะสมตามพัฒนาการ

  1. ก. แก้ให้วาดลำตัวและสัดส่วนที่ถูกต้องทันที โดยไม่ฟังเด็กเล่า
  2. ข. ชื่นชมและสนทนาถามเล่าเรื่องในภาพโดยไม่แก้รูป
  3. ค. ให้ลอกภาพคนจากหนังสือเพื่อฝึกสัดส่วน
  4. ง. บอกว่าภาพยังไม่สวยและให้วาดใหม่
ดูเฉลย
ตอบข้อ ข. ภาพแบบหัวมีขาเป็นพัฒนาการปกติ ครูควรสนับสนุนและกระตุ้นการเล่าเรื่องมากกว่าแก้ไขตามแบบผู้ใหญ่
ข้อ 10

การฝนลายพื้นผิวโดยวางกระดาษทับวัตถุแล้วใช้ดินสอหรือสีเทียนฝน เรียกว่าอะไร

  1. ก. การฝนลาย (rubbing หรือ frottage)
  2. ข. การพิมพ์ตะแกรงไหม (screen printing)
  3. ค. การปั้นนูนต่ำ (low relief)
  4. ง. การระบายสีเปียกบนเปียก (wet-on-wet)
ดูเฉลย
ตอบข้อ ก. การทาบกระดาษบนพื้นผิวและฝนด้วยดินสอหรือสีเทียนทำให้เกิดลายพื้นผิวจริงปรากฏบนกระดาษ
ข้อ 11

การปั้นแบบเสริม (additive) หมายถึงข้อใด

  1. ก. การแกะหินหรือไม้ให้ลดลงจนเป็นรูป ด้วยสิ่วและค้อนทีละชั้น
  2. ข. การเทวัสดุเหลวลงในแม่พิมพ์
  3. ค. การตัดและเชื่อมโลหะให้เป็นรูป
  4. ง. การเติมหรือพอกดินเพิ่มเข้าไปจนได้รูปทรง
ดูเฉลย
ตอบข้อ ง. การปั้นแบบเสริมคือการเพิ่มวัสดุเข้าไป ส่วนการแกะสลักเป็นการตัดทอนออก
ข้อ 12

สุนทรียศาสตร์ (aesthetics) เป็นแขนงหนึ่งของปรัชญาที่ศึกษาเรื่องใด

  1. ก. ความจริงและเหตุผลของการคิด
  2. ข. ความงามและการรับรู้คุณค่าของศิลปะ
  3. ค. ความดีและความถูกต้องทางศีลธรรม
  4. ง. ที่มาของจักรวาลและสิ่งมีชีวิต
ดูเฉลย
ตอบข้อ ข. สุนทรียศาสตร์ศึกษาธรรมชาติของความงาม ศิลปะ และประสบการณ์การรับรู้คุณค่าทางความงาม
ข้อ 13

การฝึกวาดแบบ blind contour คือมองวัตถุและเคลื่อนมือตามขอบโดยไม่มองกระดาษ มีจุดประสงค์หลักข้อใด

  1. ก. ฝึกการสังเกตและการประสานงานของตากับมือ
  2. ข. ฝึกการลงสีให้เรียบเสมอกันทั้งผืนผ้าใบและกระดาษ
  3. ค. ฝึกผสมสีคู่ตรงข้าม
  4. ง. ฝึกการลอกลายจากต้นแบบ
ดูเฉลย
ตอบข้อ ก. การไม่มองกระดาษบังคับให้ผู้เรียนสังเกตขอบวัตถุอย่างละเอียด และเชื่อมการมองกับการเคลื่อนมือ
ข้อ 14

เครื่องสังคโลกเป็นเครื่องปั้นดินเผาที่มีชื่อเสียงของสมัยใด

  1. ก. รัตนโกสินทร์
  2. ข. ธนบุรี
  3. ค. ล้านช้าง
  4. ง. สุโขทัย
ดูเฉลย
ตอบข้อ ง. สังคโลกเป็นเครื่องถ้วยเคลือบสมัยสุโขทัย ผลิตที่ศรีสัชนาลัยและสุโขทัย
ข้อ 15

วิหารพาร์เธนอน (Parthenon) ตั้งอยู่ในเมืองใด

  1. ก. โรม ประเทศอิตาลี
  2. ข. ไคโร ประเทศอียิปต์
  3. ค. ปารีส ประเทศฝรั่งเศส
  4. ง. เอเธนส์ ประเทศกรีซ
ดูเฉลย
ตอบข้อ ง. พาร์เธนอนเป็นวิหารศิลปะกรีกบนเนินอะโครโปลิสในกรุงเอเธนส์

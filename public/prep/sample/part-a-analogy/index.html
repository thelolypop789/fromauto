ข้อสอบครูผู้ช่วย ภาค ก คิดวิเคราะห์ อุปมาอุปไมย พร้อมเฉลย

โจทย์อุปมาอุปไมย (วิชาคิดวิเคราะห์ ภาค ก) พร้อมเฉลยและเหตุผลทุกข้อ ลองตอบในใจก่อน แล้วกด "ดูเฉลย"

ข้อ 1

ข้อใดมีความสัมพันธ์แบบเหตุและผลเหมือน ขี้เกียจเรียน : สอบตก

  1. ก. ทะเล : ปลา
  2. ข. ขับรถเร็ว : อุบัติเหตุ
  3. ค. ปากกา : ดินสอ
  4. ง. หมอ : คนไข้
ดูเฉลย
ตอบข้อ ข. ความขี้เกียจเรียนเป็นสาเหตุของการสอบตก เช่นเดียวกับการขับรถเร็วเป็นสาเหตุของอุบัติเหตุ
ข้อ 2

ปลา : เหงือก = คน : ?

  1. ก. หัวใจ
  2. ข. จมูก
  3. ค. ปอด
  4. ง. ผิวหนัง
ดูเฉลย
ตอบข้อ ค. ปลาใช้เหงือกเป็นอวัยวะหายใจ คนใช้ปอดเป็นอวัยวะหายใจ
ข้อ 3

เช้า : กลางวัน = เย็น : ?

  1. ก. กลางคืน
  2. ข. บ่าย
  3. ค. สาย
  4. ง. เที่ยง
ดูเฉลย
ตอบข้อ ก. เป็นความสัมพันธ์แบบลำดับ ช่วงเวลาที่ต่อจากเช้าคือกลางวัน และช่วงเวลาที่ต่อจากเย็นคือกลางคืน
ข้อ 4

ร้อน : หนาว = สูง : ?

  1. ก. ใหญ่
  2. ข. ยาว
  3. ค. ไกล
  4. ง. ต่ำ
ดูเฉลย
ตอบข้อ ง. ร้อนกับหนาวมีความหมายตรงข้ามกัน คำที่มีความหมายตรงข้ามกับสูงคือต่ำ
ข้อ 5

สุนัข : สัตว์ = กุหลาบ : ?

  1. ก. สีแดง
  2. ข. สวน
  3. ค. ดอกไม้
  4. ง. หนาม
ดูเฉลย
ตอบข้อ ค. เป็นความสัมพันธ์ระหว่างสมาชิกกับประเภท สุนัขเป็นสัตว์ชนิดหนึ่ง กุหลาบเป็นดอกไม้ชนิดหนึ่ง
ข้อ 6

ดาวอังคาร : ดาวเคราะห์ = ดวงอาทิตย์ : ?

  1. ก. ดาวเคราะห์
  2. ข. ดาวหาง
  3. ค. ดาวฤกษ์
  4. ง. ดาวเทียม
ดูเฉลย
ตอบข้อ ค. ดาวอังคารเป็นดาวเคราะห์ดวงหนึ่ง ส่วนดวงอาทิตย์เป็นดาวฤกษ์ซึ่งเปล่งแสงได้ด้วยตนเอง
ข้อ 7

Fe : เหล็ก = Au : ?

  1. ก. อะลูมิเนียม
  2. ข. ทองแดง
  3. ค. เงิน
  4. ง. ทองคำ
ดูเฉลย
ตอบข้อ ง. Fe เป็นสัญลักษณ์ธาตุของเหล็ก และ Au เป็นสัญลักษณ์ธาตุของทองคำ ส่วนเงินคือ Ag
ข้อ 8

ข้อใดมีความสัมพันธ์เหมือน อินทรี : นก

  1. ก. เต่า : สัตว์สะเทินน้ำสะเทินบก
  2. ข. วาฬ : ปลา
  3. ค. ฉลาม : ปลา
  4. ง. ค้างคาว : นก
ดูเฉลย
ตอบข้อ ค. อินทรีเป็นนกชนิดหนึ่ง และฉลามเป็นปลาชนิดหนึ่ง ส่วนค้างคาวและวาฬเป็นสัตว์เลี้ยงลูกด้วยนม และเต่าเป็นสัตว์เลื้อยคลาน
ข้อ 9

เดิน : วิ่ง = กระซิบ : ?

  1. ก. เขียน
  2. ข. ฟัง
  3. ค. ตะโกน
  4. ง. เงียบ
ดูเฉลย
ตอบข้อ ค. วิ่งเป็นการเคลื่อนที่ที่แรงและเร็วกว่าเดิน ตะโกนเป็นการเปล่งเสียงที่ดังกว่ากระซิบมาก
ข้อ 10

12 : 4 = 27 : ?

  1. ก. 3
  2. ข. 6
  3. ค. 9
  4. ง. 12
ดูเฉลย
ตอบข้อ ค. 4 ได้จาก 12 ÷ 3 ดังนั้นคู่ของ 27 คือ 27 ÷ 3 เท่ากับ 9
ข้อ 11

ข้อใดมีความสัมพันธ์แบบเหตุและผลเหมือน ตัดไม้ทำลายป่า : ดินถล่ม

  1. ก. ชาวประมง : แห
  2. ข. ปล่อยน้ำเสียลงแม่น้ำ : ปลาตาย
  3. ค. ปลา : เหงือก
  4. ง. แม่น้ำ : ทะเล
ดูเฉลย
ตอบข้อ ข. การตัดไม้ทำลายป่าเป็นเหตุให้เกิดดินถล่ม เช่นเดียวกับการปล่อยน้ำเสียลงแม่น้ำเป็นเหตุให้ปลาตาย
ข้อ 12

5 : 11 = 8 : ?

  1. ก. 16
  2. ข. 17
  3. ค. 18
  4. ง. 15
ดูเฉลย
ตอบข้อ ข. 11 ได้จาก 5 × 2 + 1 ดังนั้นคู่ของ 8 คือ 8 × 2 + 1 เท่ากับ 17
ข้อ 13

16 : 4 = 81 : ?

  1. ก. 27
  2. ข. 9
  3. ค. 18
  4. ง. 3
ดูเฉลย
ตอบข้อ ข. 4 คือรากที่สองของ 16 ดังนั้นคู่ของ 81 คือรากที่สองของ 81 เท่ากับ 9
ข้อ 14

3 : 27 = 4 : ?

  1. ก. 81
  2. ข. 16
  3. ค. 64
  4. ง. 12
ดูเฉลย
ตอบข้อ ค. 27 คือ 3 ยกกำลังสาม ดังนั้นคู่ของ 4 คือ 4 ยกกำลังสาม เท่ากับ 64
ข้อ 15

ไฟฟ้าลัดวงจร : ไฟไหม้ = ฝนตกหนัก : ?

  1. ก. เมฆ
  2. ข. น้ำท่วม
  3. ค. ร่ม
  4. ง. ฤดูฝน
ดูเฉลย
ตอบข้อ ข. เป็นความสัมพันธ์แบบเหตุกับผล ไฟฟ้าลัดวงจรเป็นสาเหตุของไฟไหม้ ฝนตกหนักเป็นสาเหตุของน้ำท่วม

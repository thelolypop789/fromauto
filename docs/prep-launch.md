# FormAuto Prep (/prep) — launch checklist

ระบบซ้อมข้อสอบครูผู้ช่วย อยู่ที่ `/prep` แยก bundle / session / ตารางจากระบบครูเดิม

## 1. Supabase (ทำครั้งเดียว)

1. **SQL Editor** รันตามลำดับ:
   - `supabase/migrations/20261015120000_prep_schema.sql`
   - `supabase/migrations/20261015120100_prep_topics_seed.sql`
2. **Settings → API → Exposed schemas**: ต้อง **ไม่มี** `prep` (มีแค่ `public`)
3. **Authentication → Providers → Google**: เปิดอยู่แล้ว (ใช้ร่วมกับระบบครู)
4. **Authentication → URL Configuration → Redirect URLs**: เพิ่ม `https://<โดเมน>/prep`
5. **Authentication → SMTP Settings**: ตั้ง SMTP ภายนอก (Resend / Brevo) — อีเมลในตัวส่งได้เฉพาะอีเมลสมาชิกทีม
   และประมาณ 2 ฉบับ/ชม. จึงใช้ OTP ไม่ได้จริง
   - **Authentication → Email Templates**: แก้ทั้ง **Confirm signup** (ผู้ใช้ใหม่) และ **Magic Link** (ผู้ใช้เดิม) ให้มี `{{ .Token }}` ในเนื้อหา เพื่อให้อีเมลมีรหัส 6 หลัก
6. สมัครเข้า `/prep` ด้วยบัญชีของคุณหนึ่งครั้ง แล้วตั้งตัวเองเป็นแอดมิน:
   ```sql
   insert into prep.admins (user_id)
   select id from auth.users where email = 'อีเมลของคุณ';
   ```

## 2. นำเข้าข้อสอบ

เข้า `/prep` → แท็บ **แอดมิน → นำเข้า** แล้วอัปโหลดตามลำดับ:

| ไฟล์ | จำนวน | สถานะหลังนำเข้า |
|---|---|---|
| `content/prep/bank-approved.json` | 737 | เผยแพร่ทันที (ข้อสรุปจากชีทที่ไม่มีอ้างอิงกฎหมาย + ข้อที่สร้างด้วยโค้ด) |
| `content/prep/bank-review.json` | 303 | รอตรวจ — ข้อที่อ้างกฎหมาย/มีธงให้ตรวจ ไปที่แท็บ **ตรวจข้อสอบ** แล้วกด อนุมัติ/ซ่อน |

- ข้อซ้ำถูกข้ามอัตโนมัติ นำเข้าซ้ำได้โดยไม่เกิดข้อซ้ำ
- สร้างข้อคำนวณเพิ่มด้วยโค้ด: `python3 scripts/prep/gen_quant.py out.json --seed 2 --scale 3` แล้วนำเข้าเลือก "สร้างด้วยโค้ด"
- **ลิขสิทธิ์:** ข้อสอบสร้างจากชีทสรุปที่ได้รับมา ตรวจว่าเจ้าของชีทอนุญาตให้นำไปเผยแพร่เชิงพาณิชย์ก่อนเปิดขาย

## 3. ตั้งค่าหน้าซื้อ

แก้ `src/prep/config.ts` (ราคา เลขบัญชี ช่องทางติดต่อ) แล้ว deploy

## 4. ขายและออกคีย์

แท็บ **แอดมิน → คีย์**: ใส่หมายเหตุ (ชื่อ/ยอด/เวลาโอน) → สร้าง → ส่งคีย์ให้ผู้ซื้อ
เช็กยอดเงินเข้าในแอปธนาคารก่อนทุกครั้ง คีย์แสดงครั้งเดียว ใช้ได้ครั้งเดียวและผูกกับบัญชีที่กรอก

## 5. ก่อนเปิดขายจริง

- Vercel Pro (Hobby ห้ามใช้เชิงพาณิชย์) และ Supabase Pro (มี backup)
- หน้าเงื่อนไขการใช้งาน / นโยบายความเป็นส่วนตัว (PDPA)
- รัน `supabase` test: ผู้ใช้ A อ่านข้อมูลของ B ไม่ได้, ไม่ล็อกอินเรียก `prep_me` ไม่ได้ (ดูชุดทดสอบในเซสชันพัฒนา)

## สถาปัตยกรรมสั้นๆ

- ตารางทั้งหมดอยู่ใน schema `prep` (ไม่เปิดผ่าน API) — เบราว์เซอร์เรียกได้เฉพาะฟังก์ชัน `public.prep_*`
- เฉลยส่งกลับเฉพาะข้อที่ตอบแล้ว, ตรวจคะแนนและโควต้าฟรี 3 ชุดในฐานข้อมูล
- แอดมินคือบัญชีใน `prep.admins` (ไม่ใช้ License Key ของ FormAuto)

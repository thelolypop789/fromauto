ข้อสอบครูผู้ช่วย วิชาเอกคณิตศาสตร์ พร้อมเฉลย

แนวข้อสอบวิชาเอกคณิตศาสตร์ ลอการิทึม ตรีโกณมิติ แคลคูลัส การสอนคณิตศาสตร์ พร้อมเฉลยและวิธีคิด ลองตอบในใจก่อน แล้วกด "ดูเฉลย"

ข้อ 1

คำตอบของสมการ log₂(x + 1) = 4 คือข้อใด

  1. ก. 15
  2. ข. 16
  3. ค. 7
  4. ง. 8
ดูเฉลย
ตอบข้อ ก. จากนิยามลอการิทึม x + 1 = 2⁴ = 16 ดังนั้น x = 15 ส่วน 16 เป็นค่าของ x + 1
ข้อ 2

โรงงานมีต้นทุนส่วนเพิ่ม C′(x) = 6x + 10 บาทต่อชิ้น และมีต้นทุนคงที่ 100 บาท ต้นทุนรวมของการผลิต 10 ชิ้นเท่ากับข้อใด

  1. ก. 400 บาท
  2. ข. 500 บาท
  3. ค. 160 บาท
  4. ง. 760 บาท
ดูเฉลย
ตอบข้อ ข. C(x) = 3x² + 10x + 100 ดังนั้น C(10) = 300 + 100 + 100 = 500 บาท ส่วน 400 บาทไม่รวมต้นทุนคงที่
ข้อ 3

สูตรเปลี่ยนฐานของลอการิทึม log_a b ตรงกับข้อใด (เมื่อ a, b > 0 และ a ≠ 1)

  1. ก. log b / log a
  2. ข. log a / log b
  3. ค. log b · log a
  4. ง. log b − log a
ดูเฉลย
ตอบข้อ ก. การเปลี่ยนฐานให้ log_a b = (log b)/(log a) ในฐานใดก็ได้ที่เป็นบวกและไม่เท่ากับ 1
ข้อ 4

วัตถุเคลื่อนที่ตามเส้นตรงโดยมีตำแหน่ง s(t) = t³ − 6t² + 9t (t ≥ 0) ณ เวลาแรกที่วัตถุหยุดนิ่งชั่วขณะ ความเร่งเท่ากับข้อใด

  1. ก. 6
  2. ข. 12
  3. ค. −6
  4. ง. −12
ดูเฉลย
ตอบข้อ ค. v(t) = 3t² − 12t + 9 = 0 ที่ t = 1 และ 3 ความเร่ง a(t) = 6t − 12 ดังนั้นที่ t = 1 ได้ a = −6
ข้อ 5

สามเหลี่ยม ABC มี a = 10, A = 30° และ B = 45° ความยาวด้าน b เท่ากับข้อใด

  1. ก. 5√2
  2. ข. 10√2
  3. ค. 10√3
  4. ง. 20
ดูเฉลย
ตอบข้อ ข. จากกฎของไซน์ b = a sin B / sin A = 10(√2/2)/(1/2) = 10√2
ข้อ 6

เส้นตรงที่ผ่านจุด (1, 3) และ (4, 9) มีสมการตรงกับข้อใด

  1. ก. 2x − y − 1 = 0
  2. ข. x − 2y + 5 = 0
  3. ค. 2x − y + 1 = 0
  4. ง. 3x − y = 0
ดูเฉลย
ตอบข้อ ค. ความชัน = (9 − 3)/(4 − 1) = 2 จึงได้ y − 3 = 2(x − 1) หรือ 2x − y + 1 = 0
ข้อ 7

สำหรับวงรีที่มีความยาวกึ่งแกนเอก a และกึ่งแกนโท b ระยะ c จากจุดศูนย์กลางถึงโฟกัสสัมพันธ์กันตามข้อใด

  1. ก. c² = a² + b²
  2. ข. c = a − b
  3. ค. c² = b² − a²
  4. ง. c² = a² − b²
ดูเฉลย
ตอบข้อ ง. วงรีมี a > b และ c² = a² − b² ส่วน c² = a² + b² เป็นความสัมพันธ์ของไฮเพอร์โบลา
ข้อ 8

นักเรียนเชื่อว่า 0.999… น้อยกว่า 1 เล็กน้อย ข้อใดวิเคราะห์ได้ถูกต้อง

  1. ก. 0.999… น้อยกว่า 1 เพราะต่อ 9 ไปกี่หลักก็ไม่ถึง 1
  2. ข. 0.999… มากกว่า 1 เพราะมีเลข 9 ต่อกันไม่รู้จบ
  3. ค. เปรียบเทียบไม่ได้ เพราะ 0.999… ไม่ใช่จำนวนจริง
  4. ง. 0.999… เท่ากับ 1 เพราะ 10x − x = 9 เมื่อ x = 0.999…
ดูเฉลย
ตอบข้อ ง. ทศนิยมซ้ำ 0.999… คือขีดจำกัดของผลบวกอนันต์ 9/10 + 9/100 + … = (9/10)/(1 − 1/10) = 1 และวิธีของ x ก็ให้ x = 1
ข้อ 9

ถ้า a > 0 และ b > 0 ข้อใดเป็นสมบัติของลอการิทึมที่ถูกต้อง

  1. ก. log(a + b) = log a · log b
  2. ข. log(ab) = log a + log b
  3. ค. log(a/b) = (log a)/(log b)
  4. ง. log aⁿ = (log a)ⁿ
ดูเฉลย
ตอบข้อ ข. ลอการิทึมของผลคูณเท่ากับผลบวกของลอการิทึม ส่วนข้ออื่นเป็นความเข้าใจคลาดเคลื่อนที่พบบ่อย
ข้อ 10

ค่าของ (−8)^(1/3) ในระบบจำนวนจริงเท่ากับข้อใด

  1. ก. −2
  2. ข. 2
  3. ค. −4
  4. ง. ไม่นิยาม
ดูเฉลย
ตอบข้อ ก. รากที่สามของ −8 คือ −2 เพราะ (−2)³ = −8 รากที่สามของจำนวนลบนิยามในระบบจำนวนจริง
ข้อ 11

จัดนักเรียน 5 คนนั่งรอบโต๊ะกลมโดยพิจารณาตำแหน่งสัมพัทธ์ มีกี่วิธี

  1. ก. 120 วิธี
  2. ข. 60 วิธี
  3. ค. 12 วิธี
  4. ง. 24 วิธี
ดูเฉลย
ตอบข้อ ง. การเรียงรอบวงกลม n ชิ้นได้ (n − 1)! = 4! = 24 ส่วน 120 คือการเรียงเป็นแถวตรง
ข้อ 12

นักเรียนเชื่อว่าลิมิตของ f(x) ที่ x → a ต้องเท่ากับ f(a) เสมอ ครูควรใช้ตัวอย่างใดชี้ให้เห็นว่าไม่จริง

  1. ก. f(x) = 2x + 1 ที่ x → 1 ซึ่ง f(1) = 3
  2. ข. f(x) = x² + 1 ที่ x → 2 ซึ่ง f(2) = 5
  3. ค. f(x) = (x² − 1)/(x − 1) ที่ x → 1 ซึ่ง f(1) ไม่นิยาม
  4. ง. f(x) = 5 ที่ x → 0 ซึ่ง f(0) = 5
ดูเฉลย
ตอบข้อ ค. ตัวอย่างค้านต้องเป็นกรณีที่ลิมิตกับค่าฟังก์ชันไม่ตรงกัน ส่วนอีกสามตัวอย่างเป็นฟังก์ชันต่อเนื่องจึงให้ค่าเท่ากัน
ข้อ 13

อนุพันธ์ของ f(x) = xⁿ (n เป็นจำนวนจริง) ตรงกับข้อใด

  1. ก. n·xⁿ⁻¹
  2. ข. xⁿ⁻¹
  3. ค. n·xⁿ
  4. ง. xⁿ⁺¹/(n + 1)
ดูเฉลย
ตอบข้อ ก. กฎกำลังของอนุพันธ์คือ d/dx(xⁿ) = n·xⁿ⁻¹ ส่วน xⁿ⁺¹/(n + 1) เป็นปริพันธ์ของ xⁿ
ข้อ 14

นักเรียนแก้สมการ (x − 2)(x − 3) = 6 โดยให้ x − 2 = 2 และ x − 3 = 3 ข้อใดวิเคราะห์ข้อผิดพลาดได้ถูกต้อง

  1. ก. แยกตัวประกอบผิดเพราะ (x − 2)(x − 3) ต้องเท่ากับ x² + 5x + 6
  2. ข. สมการนี้ไม่มีคำตอบที่เป็นจำนวนจริง จึงทำตามวิธีใดก็ไม่ได้
  3. ค. ใช้สมบัติผลคูณเป็นศูนย์กับกรณีที่ผลคูณเท่ากับ 6 ซึ่งทำไม่ได้ ต้องจัดรูปเป็น x² − 5x = 0 ก่อน
  4. ง. ควรหารทั้งสองข้างด้วย x − 2 ก่อน แล้วจึงแก้สมการที่เหลือ
ดูเฉลย
ตอบข้อ ค. สมบัติ ab = 0 แล้ว a = 0 หรือ b = 0 ใช้ได้เฉพาะเมื่อผลคูณเป็นศูนย์ สมการนี้เป็น x² − 5x = 0 ได้ x = 0 หรือ x = 5
ข้อ 15

สมการ 2cos²x − cos x − 1 = 0 มีคำตอบในช่วง [0, 2π) กี่คำตอบ

  1. ก. 2
  2. ข. 3
  3. ค. 4
  4. ง. 5
ดูเฉลย
ตอบข้อ ข. แยกตัวประกอบ (2cos x + 1)(cos x − 1) = 0 ได้ cos x = −1/2 (x = 2π/3, 4π/3) หรือ cos x = 1 (x = 0) รวม 3 คำตอบ

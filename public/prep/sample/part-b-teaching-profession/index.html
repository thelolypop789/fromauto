ข้อสอบครูผู้ช่วย ภาค ข วิชาชีพครู พร้อมเฉลย

จิตวิทยา การจัดการชั้นเรียน การวัดและประเมินผล หลักสูตร นวัตกรรม และวิจัย พร้อมเฉลยและคำอธิบาย ลองตอบในใจก่อน แล้วกด "ดูเฉลย"

ข้อ 1

ทฤษฎีการวางเงื่อนไขแบบการกระทำ (Operant Conditioning) เป็นของใคร

  1. ก. ธอร์นไดค์
  2. ข. พาฟลอฟ
  3. ค. สกินเนอร์
  4. ง. วัตสัน
ดูเฉลย
ตอบข้อ ค. สกินเนอร์พัฒนาทฤษฎีการวางเงื่อนไขแบบการกระทำโดยทดลองกับหนูและนกพิราบในกล่องสกินเนอร์
ข้อ 2

ในวง PLC ครูคนหนึ่งเสนอว่าผลการเรียนต่ำเป็นเพราะนักเรียนไม่ตั้งใจและผู้ปกครองไม่ดูแล จึงไม่ต้องปรับการสอน ข้อคิดเห็นนี้ขัดกับหลักของ PLC อย่างไร

  1. ก. PLC ห้ามพูดถึงผู้ปกครองในทุกกรณี
  2. ข. PLC ให้ผู้บริหารตัดสินแทนครูทั้งหมด
  3. ค. PLC ไม่เกี่ยวข้องกับผลการเรียนของนักเรียน
  4. ง. PLC เน้นการมุ่งผลลัพธ์ของผู้เรียนและการปรับปรุงการจัดการเรียนรู้ของครู มากกว่าการโทษปัจจัยภายนอก
ดูเฉลย
ตอบข้อ ง. หัวใจของ PLC คือความรับผิดชอบร่วมต่อการเรียนรู้ของผู้เรียน ครูจึงต้องสะท้อนและพัฒนาการสอนของตนเอง
ข้อ 3

สมมติฐาน “ผลสัมฤทธิ์ของนักเรียนที่เรียนด้วยวิธีสอนแบบ ก และแบบ ข แตกต่างกัน” เป็นสมมติฐานประเภทใด

  1. ก. สมมติฐานศูนย์ที่ระบุว่าไม่แตกต่าง
  2. ข. ไม่ใช่สมมติฐาน
  3. ค. สมมติฐานแบบไม่มีทิศทาง
  4. ง. สมมติฐานแบบมีทิศทาง
ดูเฉลย
ตอบข้อ ค. สมมติฐานที่ระบุเพียงว่าแตกต่างกันโดยไม่บอกว่าสูงกว่าหรือต่ำกว่า เป็นสมมติฐานแบบไม่มีทิศทาง
ข้อ 4

จุดมุ่งหมายที่แท้จริงของการบริหารจัดการชั้นเรียนคือข้อใด

  1. ก. ทำให้ห้องเรียนเงียบที่สุดตลอดเวลา
  2. ข. ทำให้นักเรียนเชื่อฟังครูโดยไม่ตั้งคำถาม
  3. ค. จัดสภาพแวดล้อมและบรรยากาศให้เอื้อต่อการเรียนรู้อย่างมีประสิทธิภาพ
  4. ง. ลดภาระการสอนของครูให้มากที่สุด
ดูเฉลย
ตอบข้อ ค. การบริหารจัดการชั้นเรียนมุ่งสร้างเงื่อนไขที่ทำให้ผู้เรียนเรียนรู้ได้ดีที่สุด ความเงียบหรือการเชื่อฟังไม่ใช่เป้าหมายในตัวเอง
ข้อ 5

แนวทางการสื่อสารระหว่างบ้านกับโรงเรียนที่มีประสิทธิภาพที่สุดคือข้อใด

  1. ก. สื่อสารอย่างสม่ำเสมอ ทั้งความก้าวหน้า ความสำเร็จ และเรื่องที่ต้องพัฒนา
  2. ข. ติดต่อผู้ปกครองเฉพาะเมื่อนักเรียนทำผิด
  3. ค. สื่อสารเฉพาะช่วงประกาศผลปลายภาค
  4. ง. ให้นักเรียนเป็นผู้แจ้งข้อมูลทั้งหมดแทนครู
ดูเฉลย
ตอบข้อ ก. การสื่อสารสม่ำเสมอและมีเรื่องเชิงบวกช่วยสร้างความไว้วางใจ ทำให้ผู้ปกครองพร้อมร่วมมือเมื่อเกิดปัญหา
ข้อ 6

ขั้นตอนแรกของการจัดการเรียนรู้แบบสืบเสาะหาความรู้ 5 ขั้น (5E) คือข้อใด

  1. ก. ขั้นสร้างความสนใจ (Engagement)
  2. ข. ขั้นสำรวจและค้นหา (Exploration)
  3. ค. ขั้นอธิบายและลงข้อสรุป (Explanation)
  4. ง. ขั้นขยายความรู้ (Elaboration)
ดูเฉลย
ตอบข้อ ก. รูปแบบ 5E เริ่มจากขั้นสร้างความสนใจ แล้วจึงสำรวจและค้นหา อธิบายและลงข้อสรุป ขยายความรู้ และประเมิน ตามลำดับ
ข้อ 7

ข้อความ “การวัดผลทางการศึกษาเป็นการวัดทางอ้อม” มีความหมายตรงกับข้อใด

  1. ก. การวัดต้องให้ผู้อื่นตอบแทนผู้เรียนเสมอ
  2. ข. การวัดต้องอาศัยข้อมูลจากผู้ปกครองเป็นหลัก
  3. ค. คุณลักษณะที่วัด เช่น ความรู้หรือเจตคติ ไม่สามารถวัดได้โดยตรง ต้องอนุมานจากพฤติกรรมที่ผู้เรียนแสดงออกต่อสิ่งเร้า
  4. ง. การวัดสามารถทำได้โดยไม่ต้องใช้เครื่องมือใด ๆ
ดูเฉลย
ตอบข้อ ค. คุณลักษณะทางการศึกษาเป็นนามธรรม จึงต้องวัดผ่านพฤติกรรมตอบสนองต่อสิ่งเร้า เช่น ข้อสอบ แล้วอนุมานกลับไปยังคุณลักษณะนั้น
ข้อ 8

ข้อใดไม่ใช่ด้านของความเข้าใจ 6 ด้าน (Six Facets of Understanding) ตามแนวคิดของวิกกินส์และแม็กไท

  1. ก. การอธิบาย
  2. ข. การมีมุมมอง
  3. ค. การรู้จักตนเอง
  4. ง. การจดจำข้อมูลได้อย่างแม่นยำ
ดูเฉลย
ตอบข้อ ง. ความเข้าใจ 6 ด้าน ได้แก่ การอธิบาย การแปลความ การประยุกต์ใช้ การมีมุมมอง การเข้าใจผู้อื่น และการรู้จักตนเอง
ข้อ 9

การคิดเชิงนามธรรม (Abstraction) ในแนวคิดเชิงคำนวณหมายถึงข้อใด

  1. ก. การแบ่งปัญหาออกเป็นส่วนย่อย
  2. ข. การเขียนลำดับขั้นตอนการทำงานอย่างชัดเจน
  3. ค. การคัดเลือกเฉพาะสาระสำคัญของปัญหาและตัดรายละเอียดที่ไม่จำเป็นออก
  4. ง. การค้นหาความเหมือนหรือรูปแบบที่ซ้ำกัน
ดูเฉลย
ตอบข้อ ค. Abstraction ช่วยให้มองเห็นแก่นของปัญหาโดยละเลยรายละเอียดที่ไม่เกี่ยวข้อง
ข้อ 10

น้ำหนักและส่วนสูงของนักเรียนจัดอยู่ในมาตรการวัดระดับใด

  1. ก. เรียงอันดับ (Ordinal Scale)
  2. ข. อันตรภาค (Interval Scale)
  3. ค. อัตราส่วน (Ratio Scale)
  4. ง. นามบัญญัติ (Nominal Scale)
ดูเฉลย
ตอบข้อ ค. น้ำหนักและส่วนสูงมีศูนย์แท้และนำมาเปรียบเทียบเป็นอัตราส่วนได้ จึงเป็นมาตรอัตราส่วน
ข้อ 11

ค่าความยากง่าย (p) ของข้อสอบที่ถือว่าเหมาะสมโดยทั่วไปอยู่ในช่วงใด

  1. ก. 0.90–1.00
  2. ข. −1.00–0.00
  3. ค. 0.20–0.80
  4. ง. 0.00–0.10
ดูเฉลย
ตอบข้อ ค. ข้อสอบที่มีค่า p ระหว่าง 0.20–0.80 ถือว่ามีความยากง่ายพอเหมาะ
ข้อ 12

เนื้อหาเรื่องศาสนา ศีลธรรม และจริยธรรม อยู่ในกลุ่มสาระการเรียนรู้ใดของหลักสูตรแกนกลางการศึกษาขั้นพื้นฐาน

  1. ก. ภาษาไทย
  2. ข. สุขศึกษาและพลศึกษา
  3. ค. ศิลปะ
  4. ง. สังคมศึกษา ศาสนาและวัฒนธรรม
ดูเฉลย
ตอบข้อ ง. สาระศาสนา ศีลธรรม และจริยธรรมเป็นสาระหนึ่งในกลุ่มสาระการเรียนรู้สังคมศึกษา ศาสนาและวัฒนธรรม
ข้อ 13

ในกิจกรรม STEM นักเรียนสร้างสะพานจากไม้ไอศกรีมแล้วสะพานรับน้ำหนักได้น้อยกว่าที่คาด ครูควรทำอย่างไรจึงสอดคล้องกับกระบวนการออกแบบเชิงวิศวกรรมมากที่สุด

  1. ก. ให้คะแนนต่ำแล้วจบกิจกรรมทันที
  2. ข. สร้างสะพานให้นักเรียนดูเป็นตัวอย่างที่ถูกต้อง
  3. ค. ให้นักเรียนวิเคราะห์จุดที่ล้มเหลว ปรับปรุงแบบ และทดสอบซ้ำ
  4. ง. เปลี่ยนไปเรียนหัวข้อใหม่เพื่อไม่ให้เสียเวลา
ดูเฉลย
ตอบข้อ ค. กระบวนการออกแบบเชิงวิศวกรรมเป็นวงจรที่ต้องทดสอบ ประเมิน และปรับปรุงแบบซ้ำ ความล้มเหลวจึงเป็นโอกาสในการเรียนรู้
ข้อ 14

ชุดกิจกรรมชุดหนึ่งตั้งเกณฑ์ประสิทธิภาพ 80/80 ผลการทดลองได้ E1/E2 เท่ากับ 78/85 ข้อสรุปใดถูกต้อง

  1. ก. ยังไม่ผ่านเกณฑ์ เพราะ E1 ต่ำกว่า 80
  2. ข. ผ่านเกณฑ์ เพราะ E2 สูงกว่า 80
  3. ค. ผ่านเกณฑ์ เพราะค่าเฉลี่ยของ E1 และ E2 สูงกว่า 80
  4. ง. ยังไม่ผ่านเกณฑ์ เพราะ E2 สูงกว่า E1
ดูเฉลย
ตอบข้อ ก. การผ่านเกณฑ์ 80/80 ต้องให้ทั้ง E1 และ E2 ไม่ต่ำกว่าเกณฑ์ เมื่อ E1 = 78 จึงยังไม่ผ่านเกณฑ์
ข้อ 15

ครูบอกนักเรียนว่า "ถ้าทำแบบฝึกหัดคณิตศาสตร์เสร็จ จะได้เล่นเกมการศึกษาที่ชอบ" ครูใช้หลักการใด

  1. ก. การเสริมแรงทางลบ
  2. ข. หลักของพรีแมค (Premack principle)
  3. ค. การลงโทษแบบถอดถอน
  4. ง. การวางเงื่อนไขแบบคลาสสิก
ดูเฉลย
ตอบข้อ ข. หลักของพรีแมคใช้กิจกรรมที่ผู้เรียนชอบเป็นตัวเสริมแรงให้ทำกิจกรรมที่ชอบน้อยกว่าให้สำเร็จก่อน
ข้อ 16

นักเรียนได้คะแนน 70 จากการสอบที่มีค่าเฉลี่ย 60 และส่วนเบี่ยงเบนมาตรฐาน 5 คะแนนมาตรฐาน T ของนักเรียนคนนี้เท่ากับเท่าใด

  1. ก. 60
  2. ข. 70
  3. ค. 65
  4. ง. 2
ดูเฉลย
ตอบข้อ ข. z = (70 − 60) ÷ 5 = 2 และ T = 50 + 10z = 50 + 20 = 70
ข้อ 17

ครูประจำชั้นใช้กลุ่มไลน์ผู้ปกครองของห้องในการสื่อสาร ข้อใดเป็นการใช้งานที่เหมาะสมที่สุด

  1. ก. แจ้งรายชื่อนักเรียนที่สอบตกลงในกลุ่มเพื่อกระตุ้นผู้ปกครอง
  2. ข. ส่งภาพนักเรียนที่ทำผิดลงกลุ่มเพื่อเป็นตัวอย่าง
  3. ค. แจ้งข่าวสารส่วนรวมในกลุ่ม และแจ้งเรื่องเฉพาะของนักเรียนรายบุคคลเป็นการส่วนตัว
  4. ง. ตอบข้อความของผู้ปกครองเฉพาะเมื่อมีปัญหาร้ายแรงเท่านั้น
ดูเฉลย
ตอบข้อ ค. การแจ้งเรื่องเฉพาะบุคคลในกลุ่มรวมเป็นการเปิดเผยข้อมูลและอาจทำให้นักเรียนอับอาย จึงควรสื่อสารเป็นการส่วนตัว
ข้อ 18

ตัวอักษร C ในหลักการ CIPPA หมายถึงข้อใด

  1. ก. การร่วมมือกันทำงาน (Cooperation)
  2. ข. การสื่อสาร (Communication)
  3. ค. การสร้างความรู้ด้วยตนเอง (Construction of knowledge)
  4. ง. การคิดสร้างสรรค์ (Creativity)
ดูเฉลย
ตอบข้อ ค. CIPPA ประกอบด้วย การสร้างความรู้ การปฏิสัมพันธ์ การมีส่วนร่วมทางกาย การเรียนรู้กระบวนการ และการประยุกต์ใช้ความรู้
ข้อ 19

นักเรียนใช้สมาร์ตโฟนส่องภาพในหนังสือแล้วเห็นโมเดลหัวใจสามมิติซ้อนอยู่บนหน้ากระดาษ เป็นเทคโนโลยีใด

  1. ก. ความจริงเสมือน (VR)
  2. ข. ระบบจัดการเรียนรู้ (LMS)
  3. ค. คิวอาร์โค้ด (QR Code) เพียงอย่างเดียว
  4. ง. ความจริงเสริม (AR)
ดูเฉลย
ตอบข้อ ง. AR ซ้อนภาพหรือข้อมูลเสมือนลงบนสภาพแวดล้อมจริง ผู้ใช้ยังมองเห็นโลกจริงอยู่
ข้อ 20

การรู้เท่าทันสื่อ (Media Literacy) หมายถึงข้อใด

  1. ก. การหลีกเลี่ยงการใช้สื่อทุกประเภท
  2. ข. การเชื่อข้อมูลจากสื่อที่มีผู้ติดตามมาก
  3. ค. ความสามารถในการเข้าถึง วิเคราะห์ ประเมิน และสร้างสรรค์สื่ออย่างมีวิจารณญาณ
  4. ง. ความสามารถในการพิมพ์ได้รวดเร็ว
ดูเฉลย

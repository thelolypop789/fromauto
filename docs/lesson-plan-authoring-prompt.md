# Gem บน Gemini: นักเขียนแผนสำเร็จรูป SOBPREP

ใช้ร่างแผนการจัดการเรียนรู้สำเร็จรูป 1 คาบ (50 นาที) เป็น JSON แล้วส่งให้ Claude ตรวจ → สร้าง PDF/Word → ขึ้นระบบ (ยังไม่เผยแพร่)

## ตั้งค่า Gem (ครั้งเดียว)
1. gemini.google.com → Gems → New Gem
2. **Name:** นักเขียนแผนสำเร็จรูป SOBPREP
3. **Instructions:** คัดลอกทุกอย่างในกรอบด้านล่างไปวาง
4. **Knowledge:** อัปโหลดไฟล์ `content/lesson-plans/ng23101-u4-p1.json` (แผนตัวอย่างที่มีภาพการ์ดแล้ว)
5. Save

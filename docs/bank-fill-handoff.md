## ขั้นตอนต่อวิชา (ทำตามนี้)
1. ดูหมวดย่อยและจำนวนข้อ: SQL "หมวดย่อย" ท้ายไฟล์ → คำนวณหมวดที่ขาด
2. ดูโจทย์เดิมของหมวดที่จะเขียน (`left(stem, 90)`) เพื่อไม่เขียนเรื่องเดิม
3. เขียนสคริปต์ `scripts/prep/major_<วิชา>_bank_<yyyy_mm>.py` ด้วย `bankkit.Bank` (ดูชุด 17 พ.ย. เป็นแบบ)
   - ข้อถูกเขียนตัวแรก · ทุกข้อมีคำอธิบายว่าทำไมตัวลวงผิด · ข้อคำนวณต้องมี `assert` · ไม่อ้างเลขมาตราที่ไม่แน่ใจ
4. **คุมความยาวตัวเลือก**: ชุดแรกของทุกวิชาข้อถูกยาวที่สุด 50–80% → แก้ด้วย `b.shorter` (ย่อข้อถูก) + `b.longer` (ยืดตัวลวงที่ยาวที่สุด) จน `correct is longest` ≤ ~25% และ `big gaps` ว่าง (ยกเว้นข้อเติมไวยากรณ์/ตัวเลข)
   - ระวัง: `b.longer` แมปตามข้อความ ใช้กับตัวลวงทุกข้อที่ข้อความตรงกัน · ห้ามทำให้ตัวลวงสองตัวความหมายซ้ำกัน
5. ตรวจซ้ำกับคลังเดิมของ topic เดียวกัน (difflib ratio > 0.62 แล้วอ่านเทียบด้วยตา) → ข้อที่ความหมายซ้ำให้ตัดออกจากสคริปต์ (17 พ.ย. ตัด 11 ข้อ)
6. เพิ่มชื่อไฟล์ใน `FILES` ของ `scripts/prep/import_claude_bank.py` (tag `claude-major-YYYY-MM`) → `python3 scripts/prep/import_claude_bank.py <file> > x.sql` → `python3 scripts/prep/ops/ops.py sql x.sql`
7. อัปเดตตาราง "สถานะ" ในไฟล์นี้ แล้ว commit + push

## SQL ที่ใช้บ่อย
```sql
-- ภาพรวมทุก topic: จำนวนข้อ, ข้อยาก, คนเลือกเอก, คนซื้อ
select t.code, t.name, (select count(*) from prep.questions q where q.topic=t.code and q.status='approved') n,
  (select count(*) from prep.profiles p where p.major=t.code) chose
from prep.topics t order by t.section, t.sort;
-- หมวดย่อยของวิชา
select s.code, s.name, s.weight, count(q.id) filter (where q.status='approved') n
from prep.subtopics s left join prep.questions q on q.subtopic=s.code
where s.topic='B3-SOC' group by 1,2,3, s.sort order by s.sort;
```

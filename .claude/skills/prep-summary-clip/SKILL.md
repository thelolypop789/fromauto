# คลิปสรุป SOBPREP

ระบบอยู่ที่ `scripts/prep/video/` (Python + ffmpeg ล้วน ไม่ใช้โปรแกรมตัดต่อ)

| ไฟล์ | หน้าที่ |
|---|---|
| `note.py` | ตัวทำคลิปหลัก: storyboard JSON → เสียง TTS → ภาพสไตล์ SOBPREP → mp4 |
| `story.py` | ส่วนเสียงที่ `note.py` ใช้ (เรียก TTS, แคช, `clean()` ตัดเสียงซ่า, ต่อเสียง, ซับ) + แม่แบบฉากแบบเก่า (พื้นแดงเข้ม) |
| `lib.py` | ตัวช่วยวาด: ข้อความไทย/อังกฤษ, ตัดคำไทย (`sub_chunks`), มาสคอต, easing |
| `setup.sh` | ติดตั้งครั้งแรก: pillow/numpy/pythainlp, ฟอนต์ Prompt, secret ของ TTS → `.cache/` |
| `storyboards/<summary-id>.json` | สคริปต์ของแต่ละเรื่อง (`b2-child.json` คือตัวอย่างที่ผ่านแล้ว) |

เสียงมาจาก Edge Function `prep-media` (Gemini TTS; `GEMINI_KEY` อยู่ใน Supabase เท่านั้น) เรียกด้วย header `x-media-secret` (vault secret `media_secret`)

## ขั้นตอน

1. `cd scripts/prep/video && ./setup.sh` — ต้องขึ้น `fonts 3/3, secret ok`
2. อ่านเนื้อหาสรุปของเรื่อง (id ดูได้จาก `select id, data->>'title' from prep.summaries order by grp, sort`):
   ```sql
   select data from prep.summaries where id = '<id>'
   ```
   ผ่าน Supabase Management API (`POST https://api.supabase.com/v1/projects/diprxrkddsqmzzihjjwi/database/query`, `"read_only": true`)
   แต่ละ branch มี `title`, `ref` (มาตรา), `big` (ตัวที่ต้องจำ), `must`/`hot` (ต้องจำ/คนผิดเยอะ), `blocks` (`oops` = จุดหลอก, `memo` = เทคนิคจำ, `past` = ข้อสอบแนวปีเก่า)
3. เขียน `storyboards/<id>.json` ตามรูปแบบด้านล่าง
4. ดูภาพก่อน (ไม่เสียค่า TTS ยกเว้นประโยคใหม่): `python3 -I note.py storyboards/<id>.json out/s.png --still <วินาที>` ดูหลาย ๆ จุด
5. ทำคลิป: `python3 -I note.py storyboards/<id>.json out/<id>.mp4` (ประโยคใหม่สร้างเสียงทีละประโยค ~5 วินาที/ประโยค โดน 429 จะรอเอง)
6. ตรวจ (ด้านล่าง) แล้วส่งไฟล์ให้ผู้ใช้ด้วย SendUserFile

## เขียน storyboard

```json
{"id": "b2-child", "pages": [
  {"title": "พ.ร.บ.คุ้มครองเด็ก พ.ศ. 2546", "icon": "🧒", "say": ["ประโยคพากย์ 1", "ประโยค 2"],
   "items": [{"at": 0, "kind": "card", "text": "...", "color": "yellow", "emoji": "⚠️"}]},
  {"no": 1, "title": "\"เด็ก\" คือใคร (ม.4)", "icon": "🎂", "say": [...], "items": [...]},
  {"title": "จำง่าย ๆ", "icon": "✍️", "say": [...], "items": [...]}
]}
```
- `say` = ประโยคพากย์ของหน้านั้น ทีละประโยค; ไอเท็มโผล่ตอนเริ่มประโยคที่ `at` (เลขลำดับใน `say`)
- `no` = เลขเหรียญทองหน้าหัวข้อ (หน้าปกกับ "จำง่าย ๆ" ไม่ใส่)
- ไอเท็ม (`kind`):
  - `card` `{text, color, emoji?, big?, tape?}` — การ์ดเต็มกว้าง; `\n` ขึ้นบรรทัด; `tape: true` = สติกเกอร์ทอง "ต้องจำ"
  - `num` `{n, text}` — รายการมีเลข (ใช้ในหน้าปก)
  - `no` / `ok` `{text}` — ป้ายแดง ✗ (จุดหลอก) / เขียว ✓
  - `tags` `{tags: [[emoji, text], ...]}` — ป้ายเล็กเรียงแถว
  - `flow` `{a: {text, emoji, color}, b: {...}}` — กล่องซ้าย ▶ กล่องขวา (เคสตัวอย่าง → ผล)
  - `row` `{label, color, text}` — ป้ายสีหน้า + ข้อความ (หน้าโทษ, หน้าจำง่าย ๆ)
  - `brand` `{text}` — ปุ่มแดง เช่น "ฝึกต่อ: sobprep.com/prep"
- สี: `yellow pink blue green lilac orange white` (โทนเดียวกับหน้าสรุปแผนผังในแอป)
- หน้าหนึ่งไม่เกิน ~5 ไอเท็ม; ถ้ายาวระบบย่อเอง แต่อ่านยาก

ลำดับที่ใช้ได้ดี (60–90 วินาที, 5–6 หน้า): หน้าปก "N จุดที่ข้อสอบชอบหลอก" → 3–4 หัวข้อ (เลือก branch ที่ `must`/`hot`) แต่ละหัวข้อ = กฎ + จุดหลอก (`oops`) + เคสตัวอย่างแบบ `flow` → หน้า "จำง่าย ๆ" + `brand`

## กฎเนื้อหา (สำคัญ)

- ข้อเท็จจริงมาจาก `prep.summaries` ของเรื่องนั้นเท่านั้น ห้ามแต่งมาตรา ตัวเลข โทษ หรือ "ปีไหนออก"; `past` ระบุว่าเป็น "แนวข้อสอบ" ห้ามเรียกว่า "ข้อสอบจริง" หรือรับประกันว่าออก
- ภาษาพูดแบบติวเตอร์ผู้ชาย ลงท้าย "ครับ" ประโยคสั้น
- ประโยคพากย์: เขียนตัวเลขเป็นคำอ่านเมื่อจำเป็น ("สามเดือน", "สิบแปดปีบริบูรณ์"); เลี่ยงประโยคที่มีตัวเลขเรียงยาว ๆ (แยกเป็นหลายประโยค)
- ห้ามลอกหน้าตา ข้อความ หรือเสียงของคลิปคนอื่น และห้ามทำเสียงเลียนแบบคนจริง; ผู้ใช้อยากได้ "ฟีล" (โน้ตสว่าง ค่อย ๆ เพิ่มการ์ด มีหน้าจำง่าย ๆ) แต่หน้าตาต้องเป็นของ SOBPREP

## สไตล์ที่ผู้ใช้ตกลงแล้ว (อย่าเปลี่ยนเองโดยไม่ถาม)

- แถบหัวแดงเลือดหมู + เส้นทอง, พื้นครีม `#FBF7F1`, การ์ดโทนสีหน้าสรุป มีแถบสีซ้ายและเงานุ่ม, เหรียญทองเลขข้อ, สติกเกอร์ทอง "ต้องจำ", ลูกศรวงกลมแดง, ซับในกล่องแดงเลือดหมู, มาสคอตไฟน้อยชุดครูมุมขวาบน
- **ไม่มีเสียงเอฟเฟกต์** (ผู้ใช้ไม่ชอบเสียงฟึ่บ/ซ่าตอนเปลี่ยนประโยค); เพลงพื้นหลังให้ใส่ในแอป TikTok/YouTube ตอนโพสต์
- เสียง: `gemini-3.8-flash-tts`, voice `Charon` (ผู้ชาย), เร่ง 1.12× (`story.SPEED`)
- เนื้อหาสำคัญอยู่ระหว่าง y≈340–1350 และซับ y≈1420: ด้านล่าง ~1550+ และขวา x>960 ถูกปุ่มของ TikTok บัง

## บทเรียนเรื่อง TTS (อย่าพลาดซ้ำ)

- รุ่น 3.x **อ่านคำสั่งกำกับน้ำเสียงออกเสียงด้วย** ถ้าใส่ไว้หน้าข้อความ และไม่รองรับ systemInstruction → ส่งข้อความล้วน (`story.tts` ใส่ STYLE เฉพาะรุ่น 2.5)
- `gemini-2.5-flash-preview-tts` ปฏิเสธบางประโยค (ไม่มีเสียง, finishReason `OTHER`) โดยเฉพาะประโยคตัวเลขเยอะ → อย่าใช้สลับรุ่นในคลิปเดียว
- TTS แถม **เสียงซ่า ~0.1 วินาทีท้ายทุกประโยค** — `story.clean()` ตัดให้แล้ว (หาเสียงสั้น ๆ คล้าย noise หลังช่วงเงียบ) อย่าข้ามฟังก์ชันนี้
- โควตาต่อนาทีต่ำ: เรียกทีละประโยค (ThreadPoolExecutor(1)) และมี backoff 429 อยู่แล้ว
- แคชอยู่ที่ `.cache/tts/` (key = รุ่น+เสียง+ข้อความ) แก้ภาพแล้วเรนเดอร์ใหม่ไม่เสียค่า TTS

## ตรวจก่อนส่ง

1. `python3 -I qa.py out/<id>.mp4` → เปิดดู `out/<id>.sheet.png` (15 เฟรมทั้งคลิป): หัวข้อไม่โดนมาสคอตบัง การ์ดไม่ล้น ซับไม่ล้น
2. บรรทัดเดียวกันพิมพ์ `noise bursts: N` — ต้องเป็น 0 (เสียงซ่าแบบที่ TTS แถม)
3. ความชัด (ถ้าสงสัย): ถอดเสียงทีละประโยคด้วย faster-whisper `medium` (`pip install faster-whisper`; ส่ง PCM จาก ffmpeg เข้าไปตรง ๆ เพราะตัวอ่านไฟล์ของมันพังกับ av เวอร์ชันนี้) — อย่าถอดทั้งคลิปรวดเดียว จะได้คำเพี้ยนเป็นภาษาอื่นทั้งที่เสียงปกติ
4. บอกผู้ใช้ตรง ๆ ว่าตรวจจากภาพและตัวเลขคลื่นเสียง ไม่ได้ฟังด้วยหู

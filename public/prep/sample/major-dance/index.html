ข้อสอบครูผู้ช่วย วิชาเอกนาฏศิลป์ พร้อมเฉลย

แนวข้อสอบวิชาเอกนาฏศิลป์ นาฏศิลป์ไทย นาฏศิลป์สากล การละคร พร้อมเฉลยและคำอธิบาย ลองตอบในใจก่อน แล้วกด "ดูเฉลย"

ข้อ 1

คำว่า หน้าพาทย์ หมายถึงอะไรในการแสดงโขนละคร

  1. ก. เพลงที่ผู้ชมร้องประกอบการแสดงตามผู้ขับร้อง
  2. ข. เครื่องแต่งกายที่ตัวละครสวมใส่ในแต่ละตอน
  3. ค. ชื่อตอนต่าง ๆ ในเรื่องรามเกียรติ์ที่นำมาแสดง
  4. ง. เพลงที่ปี่พาทย์บรรเลงประกอบกริยาอาการของตัวละคร
ดูเฉลย
ตอบข้อ ง. หน้าพาทย์เป็นเพลงบรรเลงด้วยปี่พาทย์เพื่อประกอบกริยา อารมณ์ หรือเหตุการณ์ในการแสดง
ข้อ 2

เอกภาพในการออกแบบชุดการแสดงหมายถึงข้อใด

  1. ก. ใช้ท่ารำท่าเดียวตลอดการแสดง
  2. ข. ใช้สีเดียวตลอดการแสดง
  3. ค. ให้ผู้แสดงทุกคนมีบทบาทต่างกันโดยไม่เกี่ยวข้องกัน
  4. ง. ทุกองค์ประกอบสอดคล้องกันและสื่อแนวคิดเดียวกัน
ดูเฉลย
ตอบข้อ ง. เอกภาพคือความเป็นหนึ่งเดียวขององค์ประกอบ ซึ่งสนับสนุนแนวคิดหรือเรื่องราวเดียวกัน
ข้อ 3

ตำราที่ถือว่าเป็นต้นแบบทางความคิดของศิลปะการฟ้อนรำอินเดียและมีอิทธิพลต่อนาฏศิลป์ไทย คือตำราใด

  1. ก. ภรตนาฏยศาสตร์
  2. ข. ตำราพิชัยสงคราม
  3. ค. ไตรภูมิพระร่วง
  4. ง. ตำราพระโหราธิบดี
ดูเฉลย
ตอบข้อ ก. ตำราภรตนาฏยศาสตร์เป็นตำราว่าด้วยการฟ้อนรำของอินเดียซึ่งแต่งโดยพระภรตมุนี และเป็นต้นแนวคิดของนาฏศิลป์ไทย
ข้อ 4

การแสดงพื้นเมืองจำนวนมาก เช่น เต้นกำรำเคียวและเซิ้งบั้งไฟ มีเนื้อหาผูกพันกับการเกษตรและความเชื่อเรื่องฝน ข้อสรุปใดวิเคราะห์ได้เหมาะสมที่สุด

  1. ก. การแสดงพื้นเมืองสะท้อนอาชีพ วิถีชีวิต และความเชื่อของชุมชน
  2. ข. การแสดงพื้นเมืองไม่เกี่ยวข้องกับอาชีพและวิถีชีวิตของผู้คนเลย
  3. ค. การแสดงพื้นเมืองเกิดขึ้นเพื่อแข่งขันชิงรางวัลเท่านั้น
  4. ง. การแสดงพื้นเมืองถูกกำหนดแบบแผนจากราชสำนักทั้งหมด
ดูเฉลย
ตอบข้อ ก. เนื้อหาที่ผูกกับการเกษตรและฝนแสดงว่าการแสดงพื้นเมืองสะท้อนอาชีพ วิถีชีวิต และความเชื่อของท้องถิ่น
ข้อ 5

ครูต้องการให้นักเรียนเน้นลักษณะเด่นของละครนอกเมื่อจัดแสดงเรื่องไกรทอง ควรแนะนำให้เน้นข้อใด

  1. ก. เล่นช้า ประณีต และงดมุขตลกทุกฉากตลอดเรื่อง
  2. ข. ใช้ผู้แสดงเป็นหญิงล้วนในราชสำนักเท่านั้น
  3. ค. ดำเนินเรื่องกระชับรวดเร็วและมีตลกสนุกสนาน
  4. ง. ให้ผู้แสดงสวมหัวโขนปิดหน้าตลอดการแสดง
ดูเฉลย
ตอบข้อ ค. ละครนอกมีลักษณะเด่นที่ความรวดเร็วและตลก การเน้นลักษณะนี้ทำให้การแสดงตรงรูปแบบ
ข้อ 6

ข้อใดเป็นการจำแนกประเภทนาฏศิลป์ไทยที่ถูกต้อง

  1. ก. โขน บัลเลต์ แจ๊สแดนซ์ ลีลาศ และฮิปฮอป
  2. ข. โขน ละคร ระบำรำฟ้อน และการแสดงพื้นเมือง
  3. ค. ละคร ภาพวาด ประติมากรรม และสถาปัตยกรรม
  4. ง. ดนตรี ภาษา ศาสนา กีฬา และวรรณคดี
ดูเฉลย
ตอบข้อ ข. นาฏศิลป์ไทยจำแนกได้เป็นโขน ละคร ระบำรำฟ้อน และการแสดงพื้นเมือง ส่วนบัลเลต์และแจ๊สเป็นนาฏศิลป์ตะวันตก
ข้อ 7

จังหวะของเพลงวอลซ์ซึ่งเป็นการเต้นลีลาศคู่ชายหญิง มีลักษณะตามข้อใด

  1. ก. สามจังหวะต่อหนึ่งห้อง
  2. ข. สองจังหวะต่อหนึ่งห้อง
  3. ค. สี่จังหวะต่อหนึ่งห้อง
  4. ง. ไม่มีการกำหนดห้องจังหวะ
ดูเฉลย
ตอบข้อ ก. เพลงวอลซ์มีจังหวะสามช่วงต่อห้อง หรือ 3/4
ข้อ 8

ฉากที่ตัวละครได้รับข่าวร้ายแล้วร้องไห้ฟูมฟาย ผู้ควบคุมดนตรีควรเลือกเพลงหน้าพาทย์ใดจึงเหมาะสมที่สุด

  1. ก. โอด
  2. ข. เชิด
  3. ค. เสมอ
  4. ง. ตระนิมิต
ดูเฉลย
ตอบข้อ ก. ทำนองเพลงโอดเหมาะกับการแสดงความโศกเศร้า จึงสอดคล้องกับฉากร้องไห้
ข้อ 9

ระหว่างที่นักเรียนฝึกรำ ครูเดินสังเกตและให้คำแนะนำเป็นรายกลุ่มเพื่อให้นักเรียนปรับปรุงท่า การกระทำของครูนี้ตรงกับการประเมินแบบใด

  1. ก. การประเมินสรุปรวมปลายปีเท่านั้น
  2. ข. การคัดเลือกนักเรียนเข้าศึกษาต่อ
  3. ค. การประเมินระหว่างเรียนเพื่อพัฒนาผู้เรียน
  4. ง. การประเมินเพื่อเปรียบเทียบโรงเรียน
ดูเฉลย
ตอบข้อ ค. การสังเกตและให้ข้อมูลย้อนกลับระหว่างเรียนเป็นการประเมินเพื่อพัฒนาผู้เรียน ไม่ใช่การประเมินสรุปรวม
ข้อ 10

ครูต้องการประเมินความเข้าใจของนักเรียนเกี่ยวกับละครรำชนิดต่าง ๆ ควรให้ทำกิจกรรมใดจึงเหมาะสมที่สุด

  1. ก. ให้ท่องชื่อละครทุกชนิดตามลำดับตัวอักษรโดยไม่อธิบาย
  2. ข. ให้เปรียบเทียบผู้แสดง เรื่อง และลักษณะเด่นของละครแต่ละชนิด
  3. ค. ให้ลอกข้อความเกี่ยวกับละครจากหนังสือเรียนทั้งเล่ม
  4. ง. ให้นับจำนวนผู้แสดงของละครทุกเรื่องที่เคยแสดงมา
ดูเฉลย
ตอบข้อ ข. การเปรียบเทียบเป็นตารางต้องใช้ความเข้าใจและการจำแนก จึงวัดผลระดับการเข้าใจได้ดีกว่าการท่องจำหรือลอกข้อความ
ข้อ 11

การแต่งกายแบบยืนเครื่องในละครรำและโขนหมายถึงข้อใด

  1. ก. การแต่งกายด้วยเสื้อผ้าสามัญชนทั่วไปในชีวิตประจำวัน
  2. ข. การไม่สวมเครื่องประดับใด ๆ นอกจากผ้านุ่งผืนเดียว
  3. ค. การแต่งกายด้วยชุดฝึกซ้อมสำหรับใช้ในห้องเรียนเท่านั้น
  4. ง. การแต่งกายครบชุดเครื่องทรงเต็มรูปแบบตามตัวละคร
ดูเฉลย
ตอบข้อ ง. ยืนเครื่องคือการแต่งกายครบเครื่องทรงอย่างเต็มรูปแบบ ซึ่งใช้กับตัวพระและตัวนางที่เป็นตัวเอก
ข้อ 12

ผู้ชมเห็นนักแสดง 8 คนแต่งกายเหมือนกัน รำท่าเดียวกันตามเพลงโดยไม่ดำเนินเรื่อง การแสดงนี้จัดเป็นประเภทใด

  1. ก. ละครใน
  2. ข. โขน
  3. ค. ลิเก
  4. ง. ระบำ
ดูเฉลย
ตอบข้อ ง. การแสดงหมู่ที่แต่งกายเหมือนกัน รำพร้อมกันและไม่ดำเนินเรื่อง จัดเป็นระบำ
ข้อ 13

คำว่า ฟ้อน ในชื่อการแสดง เช่น ฟ้อนเล็บ ฟ้อนเทียน มักใช้เรียกการแสดงของภาคใด

  1. ก. ภาคเหนือ
  2. ข. ภาคใต้
  3. ค. ภาคกลาง
  4. ง. ภาคตะวันออก
ดูเฉลย
ตอบข้อ ก. คำว่า ฟ้อน เป็นคำเรียกการรำที่นิยมใช้ในภาคเหนือ เช่น ฟ้อนเล็บและฟ้อนเทียน
ข้อ 14

ครูประเมินว่านักเรียนเห็นคุณค่าและชื่นชมนาฏศิลป์ไทยเพียงใด การประเมินนี้อยู่ในด้านใด

  1. ก. ทักษะพิสัย
  2. ข. พุทธิพิสัย
  3. ค. กายภาพพิสัย
  4. ง. จิตพิสัย
ดูเฉลย
ตอบข้อ ง. จิตพิสัยเกี่ยวกับเจตคติ ค่านิยม และความชื่นชม ส่วนทักษะพิสัยเกี่ยวกับการปฏิบัติ
ข้อ 15

ในการรำของนาฏศิลป์ไทย การย่อเข่าและยืดเข่าเป็นการควบคุมสิ่งใดของร่างกายเป็นหลัก

  1. ก. ความดังเบาของเสียงดนตรีที่ใช้ประกอบ
  2. ข. สีสันของเครื่องแต่งกายที่ผู้แสดงสวมใส่
  3. ค. ความสว่างของแสงไฟที่ส่องบนเวทีการแสดง
  4. ง. ระดับและจังหวะการเคลื่อนไหวของลำตัว
ดูเฉลย
ตอบข้อ ง. การย่อและยืดเข่าเป็นพื้นฐานที่ควบคุมระดับและจังหวะการเคลื่อนไหวของลำตัวให้สัมพันธ์กับดนตรี

ข้อสอบชุดอื่น

ภาค ก ภาษาอังกฤษภาค ก คิดวิเคราะห์: อุปมาอุปไมยภาค ข วิชาชีพครูวิชาเอกภาษาอังกฤษวิชาเอกเคมีวิชาเอกคณิตศาสตร์วิชาเอกประถมศึกษาวิชาเอกชีววิทยาวิชาเอกฟิสิกส์วิชาเอกวิทยาศาสตร์ทั่วไปวิชาเอกสังคมศึกษาวิชาเอกคอมพิวเตอร์วิชาเอกการศึกษาปฐมวัยวิชาเอกการศึกษาพิเศษวิชาเอกดนตรีวิชาเอกศิลปศึกษาวิชาเอกพลศึกษา
